Place your photo files for Shrilakshmi in this folder (public/photos/).

Examples:
- shri-1.jpg
- shri-2.jpg
- festival.jpg
- mba.jpg

In `src/data/shrilakshmi.js`, reference them using the path starting with `/photos/`:
  src: "/photos/shri-1.jpg"

If an image is missing or not yet added, the website will gracefully display a cute pastel placeholder instead of breaking!
